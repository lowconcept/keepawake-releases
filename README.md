# KeepAwake

Hält deinen Mac wach, solange Claude Code arbeitet – und lässt ihn schlafen, sobald alles fertig ist.

**[⬇︎ KeepAwake herunterladen](https://github.com/lowconcept/keepawake-releases/releases/latest/download/KeepAwake.zip)**

1. ZIP öffnen, `KeepAwake.app` in den Ordner *Programme* ziehen und starten.
2. Clawd erscheint oben in der Menüleiste.
3. Updates kommen automatisch.

Voraussetzungen: macOS 26 oder neuer, Claude Code (Desktop-App oder Terminal).
